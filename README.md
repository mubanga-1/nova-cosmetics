# ✈️Professional Landing Page

Welcome to the NOVA aesthetics professional landing page project. This project was built as a means of learning and mastering html and css principles.

## 📖 Project Overview

This project ties in together all that I learned about html and css in line with:

- Mobile First Development
- Component Based Development
- Object-Oriented CSS
- CSS3 animations and transitions
- Semantic HTML5

---

## ⚒️ Features

- Use of CSS3 animations and transitions.
- Support for devices with higher DPR (2x, 3x).
- Use of CSS grid and flexbox layout algorithms for the a beautiful and pristine design.

## 📁 Project Structure

```
|-- components/          # Contains all individual page components
|-- css/                 # Contains all css stylesheets use in project
    |-- normalize.css
    |-- styles.css
|-- images/              # Contains all images in various formats
|-- index.html           # Contains all the components compiled as a single page
|-- README.md            # Contains details about project

```
